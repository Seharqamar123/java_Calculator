# Java Calculator 🧮

A simple calculator built using Java.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

## Technologies Used

- Java
- Scanner
- Switch statements
- If-else statements

## How to Run

1. Clone the repository.
2. Open `Calculator.java`.
3. Compile and run the program.

## Example

Enter first number: 10

Enter operator (+, -, *, /): +

Enter second number: 5

Result: 15.0
