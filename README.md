# Java Calculator

A simple command-line calculator built using Java.

## Version 3.0

Version 3 improves the calculator by adding new operations and allowing users to perform multiple calculations without restarting the program.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Division-by-zero handling
* Modulus
* Power
* Repeat calculation option
* Simple menu-based interface

## Technologies Used

* Java
* Scanner
* Switch statements
* If-else statements
* Do-while loop
* Math.pow()

## How to Run

1. Clone the repository.
2. Open the project in VS Code or another Java IDE.
3. Open `CalculatorV3.java`.
4. Compile the program:

```bash
javac CalculatorV3.java
```

5. Run the program:

```bash
java CalculatorV3
```

## Example

```text
===== Java Calculator Version 3 =====

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Modulus
6. Power

Enter your choice: 6
Enter first number: 2
Enter second number: 3

Result: 8.0
```
